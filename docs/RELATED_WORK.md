# Multidojo²：相关工作与宣传表述核查

核查日期：2026-10-24。以下依据论文摘要或作者官方代码 / 项目页，核查范围不能证明“全球首个”。

| 工作 | 已公开内容 | 对本项目表述的影响 |
| --- | --- | --- |
| [EMOS / Habitat-MAS](https://arxiv.org/abs/2410.22662)，2024，修订 2025 | 异构多机器人协作框架与 benchmark，涉及操作、感知、导航和跨层物体重排。 | 不能泛称首个异构多机器人评测。 |
| [COHERENT](https://arxiv.org/abs/2409.15146)，2024，ICRA 2025 | 异构无人机、机器狗、机械臂协作；100 个长时域任务规划测试，执行反馈用于计划调整。 | 需要区分计划反馈、自进化训练和多臂低层操作。 |
| [PARTNR](https://github.com/facebookresearch/partnr-planner) | 作者官方 Habitat 人机协作 / 机器人指令任务 benchmark。 | 多智能体具身协作并非本项目首次提出。 |
| [SEEA-R1](https://arxiv.org/abs/2506.21669)，2025 | 在 ALFWorld 研究具身 agent 的自进化训练、树结构优化与多模态奖励。 | 不能泛称首个具身自进化方法或评测；该工作本身不是异构多臂操作榜单。 |
| [RoboDojo](https://arxiv.org/abs/2607.04434)，2026 | 通用机器人操作的仿真 / 真机综合评测、策略接入与公开榜单。 | Multidojo² 是独立项目；不能把本项目仿真展示说成已完成真机评测。 |
| [EmbodiedCLBench](https://arxiv.org/abs/2610.13021)，2026-10-09 | 具身自进化 agent 的持续学习 benchmark，考察基础技能向未见组合任务的迁移。 | 连“自进化具身 benchmark”也已有明确相关工作，需具体比较持续学习和训练评测协议。 |

建议公开名称：**Multidojo²**。

建议定位：**面向同构与异构多机器人协作的自进化评测平台**（self-evolution 流程目前部分实现；外部训练 API 待接入）。

目前可验证的项目特征：20 类多臂操作、每类 100 条已审核训练轨迹、每类 100 个冻结随机考试场景、多视角证据、任务物理验收、失败诊断到具体补强场景候选、签名结果提交。风扇装配为独立展示，不应混入 20 类得分与任务数。

尚不能宣传的结论：全球首个、完整自动自进化闭环已经运行、模型训练后已提升、全 2,000 场自测已通过、全任务 100% 成功、真实机器人验证。论文若主张更窄的首次贡献，需要完整相关工作比较、公开可复现实现，以及训练前后实验证据；不能只依据本次网页搜索作首次认定。
