# RoboDojo²：相关研究

RoboDojo² 聚焦同构与异构多机器人操作，连接多视角示范、随机化评测和失败驱动的训练任务设计。以下研究涵盖异构协作、具身任务规划、机器人操作评测与持续学习，为相关问题提供不同视角。

| 研究 | 主要方向 |
| --- | --- |
| [EMOS / Habitat-MAS](https://arxiv.org/abs/2410.22662) | 异构多机器人协作，涵盖操作、感知、导航与物体重排。 |
| [COHERENT](https://arxiv.org/abs/2409.15146) | 异构机器人长时序协作与任务规划，结合执行反馈调整计划。 |
| [PARTNR](https://github.com/facebookresearch/partnr-planner) | 基于 Habitat 的人机协作与具身指令任务评测。 |
| [SEEA-R1](https://arxiv.org/abs/2506.21669) | 面向具身智能体的自进化训练、树结构优化与多模态奖励研究。 |
| [RoboDojo](https://arxiv.org/abs/2607.04434) | 机器人操作的仿真与真机评测、策略评估与公开榜单。 |
| [EmbodiedCLBench](https://arxiv.org/abs/2610.13021) | 具身智能体持续学习，以及基础技能向组合任务迁移的评测。 |

## RoboDojo² 的研究重点

- **多臂协作**：在双臂、三臂、四臂与八臂组合中研究交接、接力、共同搬运、顺序叠放和并行操作。
- **同步多视角学习**：在同一时间线上保留每臂第一视角、第三视角与状态动作信息。
- **物理与任务联合验收**：将抓取、接触、支撑、放置稳定性及禁止碰撞约束纳入验收。
- **可复现评测**：通过冻结随机场景、等权任务评分与执行证据比较策略表现。
- **失败驱动的数据补强**：借助 RSI 将执行问题具体化为训练场景候选，并用复测追踪下一轮训练效果。
