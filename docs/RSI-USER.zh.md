# RSI 评估

在考试回放中选择一条已结束的记录，点击 **RSI 评估**。评估由官方服务处理，页面显示进度、评估结论、需要改进的问题，以及具体的训练任务建议。

建议可包含涉及的机械臂、物体、目标位置范围和操作要求，也可下载为训练场景候选。候选必须执行仿真并通过数据验收后，才能加入训练集。

当前完整评估服务尚待接入，页面明确标注基础诊断，不会展示虚构的完整评估结果。缺少执行数据的记录不能进行完整评估；运行异常会先提示排查环境，不直接归因为训练不足。

RSI 说明和训练建议不会修改正式考试成绩。评估由官方服务提供，公开评测代码包不包含 RSI 服务实现；用户不需要设置模型、服务地址或密钥。
