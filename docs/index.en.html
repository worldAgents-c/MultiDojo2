RSI / REPLAY → EXPLANATION → CURRICULUM

Feedback that defines the next scenarios.

Connect failure timestamps to the relevant arms and objects, distinguishing verified physical evidence from visual hypotheses. Recommendations specify tasks, position ranges, motion constraints, and acceptance criteria for candidate scenarios.

Candidate scenes enter targeted training after simulation and data validation. Improvements are then measured under the same evaluation protocol.
